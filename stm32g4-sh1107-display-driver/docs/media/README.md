# Media Checklist

Add original media that you are authorized to publish. Recommended filenames:

- `hero.jpg` — clean photo of the complete hardware setup
- `demo.gif` — 8–15 second loop showing the system operating
- `cubemx-pinout.png` — STM32CubeMX pinout/configuration screenshot
- `scope.png` — oscilloscope capture (when relevant)
- `logic-analyzer.png` — SPI/I²C capture (when relevant)

Do **not** include company documents, internal labels, serial numbers, employee badges, screens containing confidential data, or unreleased product hardware.
